# 03. 피처 엔지니어링 (Layer 1)

## 파생변수 정의

| 변수 | 계산식 | 결측 의존성 |
|---|---|---|
| 소득증감률 | (연소득 − 2년전연소득) / 2년전연소득 | 분모=0 예외처리 필요 |
| 총부채/소득비율 | Σ대출잔액 / 추정연소득 | |
| 상환부담률 | 최근12개월상환액 / 추정연소득 | |
| 카드소비/소득비율 | (신용+체크카드소비) / 추정연소득 | |
| 할부의존도 | 할부이용액 / 신용카드소비액 | 분모=0(카드소비 없음)이면 0 처리 |
| 현금서비스의존도 | 현금서비스이용액 / 추정연소득 | |
| 주거가격부담률 | 전세거래가(Layer 0 결측처리 후) / 추정연소득 | Layer 0 산출물 의존 |
| 직장변동위험도 | 직장이력건수 × sign(이직후소득증감액) | |
| 거주-근무 불일치 | 거주지코드 ≠ 근무지코드 (boolean) | |
| 소득증빙갭 | (추정연소득 − 증빙연소득) / 추정연소득 | 증빙연소득=0은 정상값(Layer 0 확인사항) |
| 신용레버리지 | Σ대출잔액 / 총자산평가금액 | |
| Thin Filer 보정 스코어 | Thin Filer=1일 때 신용평점 대체모형 (별도 로지스틱 서브모델) | |
| 자산-부채 갭 | 순자산평가금액 − Σ대출잔액 | |
| 연체심각도 | z(연체건수)+z(연체일수)+z(연체금액) | **진단모델 전용, 예측모델 입력 금지** |

## 도메인 지수 5종 (클러스터링/리스크모델 공통 입력)

```
주거비압박지수     = f(주거가격부담률, 자가거주여부, 순자산평가금액)
부채상환위험지수    = f(추정DTI, 추정LTV, 총대출건수, 상환부담률)
소득변동성지수     = f(소득증감률, 직장변동위험도, 소득증빙갭)
소비압박지수      = f(카드소비/소득비율, 할부의존도, 현금서비스의존도)
신용취약지수      = f(신용평점, ThinFiler, 연체심각도[진단모델한정])
```

구현: 각 지수는 구성 변수를 z-score 표준화 후 단순평균(초기 버전). 시간 여유 있으면 지수별 요인분석(PCA 1st component)으로 대체해 데이터 기반 가중치 산출로 고도화 (Should 항목).

## 구현 시 주의사항

- 모든 나눗셈 연산은 분모=0 케이스를 명시적으로 처리 (0으로 나누기 방지, 대체값 또는 0 반환 정의)
- `연체심각도`는 반드시 리스크 예측모델(Cox/LGBM)의 피처 목록에서 제외되어야 함 — `docs/04_modeling_clustering_survival.md`의 데이터 누수 방지 규칙과 연동
- 산출물: `layer1_features/feature_engineer.py`, 출력 `featured_dataset.parquet`
