## Layer 2-A. GMM 소프트 클러스터링

- 5행에서는 표본 부족(n=5<30)으로 **자동 스킵**됨 (`model_trained: false`) — 정상적인 방어 동작
- 1500행에서는 K=3~10 × covariance(full/diag) 조합을 모두 학습·비교 → **BIC 기준 최적: K=9, diag**
- 사전 가설 6개 유형 중 "Thin Filer형", "자산형성가능형"은 이번에도 실제 클러스터에서 관측 안 됨. 대신 가설에 없던 "신용취약형"이 2개 클러스터(cluster_2, cluster_3)에 걸쳐 등장 → `suggested_labels`에 "가설 목록 밖 - 사람 확인 필요"로 자동 플래그됨(신용취약지수가 리스크모델 피처에서는 제외돼도 클러스터링 입력으로는 계속 쓰인다는 설계, docs/04 그대로 확인)
- 클러스터 규모(soft assignment 기대값 합): 284명(cluster_6, 소비유동성위험형) ~ 29명(cluster_0, 소득공백형)까지 다양

## Layer 2-B. 위험 예측 모델

### ⚠️ 중요: 문서(docs/04)와 실제 구현이 다른 지점 (현재는 docs/04에도 반영됨)

`docs/04_modeling_clustering_survival.md`는 원래 **Cox 비례위험모형을 주모델**로 설계했지만, 실제 코드(`cox_trainer.py`)는 **비활성 스텁 상태**임. 코드에 남은 결정 기록(2026-07-08):

> KCB 데이터가 단일 시점 크로스섹션 스냅샷이라 duration(사건까지 남은 시간)을 관측할 방법이 없음. 검토한 대안 3가지(연체일수를 경과기간으로 근사/위험도 기반 합성 duration/duration 없이 event만 예측) 중 앞의 둘은 각각 "시간 방향이 反대"·"순환논증"이라는 이유로 기각하고, **"duration 없이 event(이진 라벨)만 예측"으로 채택**. 실제 패널/시계열 데이터가 확보되면 `train_cox_model()`을 구현하도록 인터페이스만 남겨둠(호출 시 `NotImplementedError`).

**현재 주모델**: 로지스틱회귀 vs LightGBM 이진분류를 학습해 held-out PR-AUC로 자동 선택 + 확률 보정(CalibratedClassifierCV).

**1500행 실행 결과**:
- event 양성비율: 19.8%
- 로지스틱 PR-AUC 0.210 vs LightGBM PR-AUC 0.248 → **LightGBM 선택**(baseline 0.198 대비 개선, 신용취약지수 리크 차단 이후로도 근사-완벽 수준(0.99+)이 아닌 현실적인 범위 유지 — 2026-07-10 스케일 리허설에서 잡은 신용취약지수 간접누수 버그가 여전히 잘 차단되고 있다는 방증)
- Spatial CV(시군구 기준): skipped=false, 정상 동작
- 공정성 감사(성별): AUC-ROC 남 0.979 / 여 0.976로 이번 합성데이터 생성 버전에서는 두 그룹 다 매우 높게 나옴 — 초기 스케일 리허설(2026-07-10) 때의 "남 0.60 vs 여 0.71" 격차보다 절대 수준 자체가 달라졌는데, 이는 합성데이터 생성 스크립트가 그 사이 개편된 영향으로 보이며 **실제 KCB 데이터의 성능을 예측하지 않는다** — 발표 전 실데이터로 재확인 필요
- 연령대 70/75세는 표본 부족(n<20)으로 자동 스킵 — 계획된 방어 로직 확인
- SHAP top3 및 확률 보정 모두 정상 산출, `risk_model.pkl`엔 배포용 보정모델 + SHAP 전용 원본 LightGBM을 분리 저장

### 공정성 보정 (차별화 항목②, 2026-07-20 추가)

성별 equalized-odds 보정임계값을 계산해 "감사에서 그치지 않고 실제로 교정"까지 확인:

| 지표 | 보정 전 | 보정 후 |
|---|---|---|
| 성별 간 TPR 격차 | 1.40%p | **0.11%p** |

`risk_threshold=0.6`(기본값)에서 `/policy-gaps`가 이 보정임계값을 자동 적용한다. 표본 부족 그룹은 기본임계값 유지(이번 실행에선 두 그룹(남/여) 모두 표본 충분해 스킵 없음).

### 정책별 예산 한계수익 / 쉐도우 프라이스 (차별화 항목③, 2026-07-20 추가)

정책 하나만 예산 10%를 올려 재풀이한 finite-difference 근사 (baseline coverage 27.3%):

| 순위 | 정책 | 한계 커버리지 증가(10%당) |
|---|---|---|
| 1 | 희망신용상담센터 | **+1.13%p** |
| 2 | 청년 중개보수·이사비 지원 | +0.67%p |
| 3 | 청년디딤돌카드 플러스 | +0.60%p |
| 4 | 청년월세지원 | +0.40%p |
| 4 | 머물자리론 | +0.40%p |
| 6 | 부산청년 기쁨두배통장 | +0.20%p |

지금 예산배분에서 추가 예산 1원당 효과가 가장 큰 정책은 "희망신용상담센터" — 예산 재배분 우선순위를 숫자로 제시.

**Thompson Sampling 시뮬레이션** (2000라운드):
- 구간별 평균 regret이 초반 0.0367 → 중반 0.0057 → 후반 0.0027로 **단조 감소** — 밴딧이 실제로 학습(수렴)하고 있음을 정량적으로 확인
- 정책별 사후평균(예: 청년월세지원 0.758, 청년 중개보수·이사비 지원 0.60)이 prior(초기 가정치)와 갈라지는 방향이 정책마다 다양 → "밴딧이 틀린 가정을 교정한다"는 데모 설득력 확보

## 위험지도 공간적 자기상관 (차별화 항목④, 2026-07-20 추가)

`web-dashboard/public/busan_districts.geojson`에서 유도한 부산 16개 시군구 인접행렬로 시군구별 평균위험점수에 대해 Global Moran's I 계산:

- **Moran's I = -0.167 (p = 0.347, 999회 순열검정) → 통계적으로 유의미하지 않음**
- 합성데이터가 지역코드와 무관한 난수로 생성돼 공간패턴이 없는 게 오히려 정상 — "우연이 아닌 군집"을 검정하는 로직 자체가 false positive 없이 정직하게 "유의미하지 않다"고 답한 것으로 봐야 함. 실데이터에서 지역별 경제위험이 실제로 군집돼 있다면 이 검정이 그걸 통계적으로 잡아낼 것.
- 영도구(26200, 섬 지역)는 육지 경계 공유가 없어 최근접 지역 폴백으로 정상 연결됨(고립 노드 없음 확인)

## 종합 결론

1. **Layer 0~3 전 구간이 5행/1500행 모두에서 에러 없이 끝까지 실행됨.** 표본 부족 시 자동 스킵(Layer 2-A), sentinel 전량 결측 시 null 허용(Layer 0) 등 방어 로직이 실제로 작동.
2. **차별화 기능 4종(위험 궤적 시뮬레이션/공정성 보정/쉐도우 프라이스/공간적 자기상관) 모두 n=1500 스케일에서 정상 동작 확인.** 특히 공정성 보정은 TPR 격차를 1.40%p→0.11%p로 실제로 줄인 것을 수치로 확인했고, 위험 궤적 시뮬레이션은 개입 시나리오가 무개입보다 낮은 위험으로 수렴하는 방향성을 확인함.
3. **문서와 구현이 갈라진 지점 1건**: Cox 생존분석은 설계 문서상 주모델이었으나, "duration을 관측할 수 없다"는 현실적 이유로 2026-07-08에 로지스틱/LightGBM 이진분류로 대체 결정됨(docs/04에 이미 반영됨). 발표 슬라이드가 여전히 Cox를 주모델로 설명하고 있다면(저장소 밖 자료) 확인 필요.
4. **Layer 4는 실제 LLM 호출 없이 폴백 경로만 검증됨.** 해커톤 당일 데모 전에는 `ANTHROPIC_API_KEY`를 설정하고 실제 Claude 응답 품질도 확인 필요.
5. **공정성 감사 수치(AUC-ROC 성별 격차)가 이전 실행(2026-07-10) 대비 절대 수준이 크게 달라짐** — 합성데이터 생성기가 그 사이 개편된 영향으로 보이며, 실제 KCB 데이터의 성능을 전혀 예측하지 않는다는 점을 다시 한번 주의(합성데이터 결과는 "파이프라인이 안 죽고 도는가" 검증용일 뿐).
6. 클러스터링(Layer 2-A)에서 사전 가설에 없던 유형이 발견된 지점은 발표 스토리("가설과 실제를 대조했다")에 그대로 활용 가능한 소재.
